# Every open item before the 0.2 tag

Compiled on 2026-10-11, when the author asked that 0.2 clear **every** open item -
nothing left "for after the release" - from every list the project keeps: the
release checklist's two sections, round three's after-release list and its
readiness report's diagnosis items, round nine's synthesis, `task-v0.2.md`, the
fast-link runbook, the README's own admissions, the decision records' open
questions, and the two reads of round nine's changes. A search agent read the
sources whole and the lead spot-checked them; ten of the items were confirmed
open in the tree by hand. **The first step of each item is to confirm, in the
tree as it then is, that it is still open, and to read its source.** The brief
that works through this list is `task-v0.2-to-the-tag.md`.

**Key.** Sources (paths under `docs/`): CT = `release-checklist.md`, "For the
0.2 tag"; CA = its "After the release" (the finding as the checklist names it);
R3 = `reviews/archive/phase1-release-review.md`'s after-release list; RD =
`reviews/archive/phase1-release-readiness.md`'s diagnosis items; R9 =
`reviews/archive/v0.2-before-part4-review.md`; FL = `fast-link.md`; TV =
`prompts/task-v0.2.md`; MS = `design/mesh-schedule-proposal.md`; RM = a line of
the README as it was on 2026-10-11; DR = a decision record; RN =
`release-notes/0.2.0.md`; AR and FC = the read and the fact-check of round
nine's changes. "A + B": both list it. Kind: impl (code), test (a test or a
model to add), meas (a run), doc, dec (the author's decision). Where: VM (the
