# Reference material

The OpenSHMEM specification is not stored in this repository. Download it from
the OpenSHMEM project at <http://www.openshmem.org/> and place it here; PDFs in
this directory are ignored by git.

| Document | Used for |
|---|---|
| OpenSHMEM Application Programming Interface, Version 1.6 (1 November 2024) | Target specification. Section numbers of the form §9.x.y in the design notes refer to it |
